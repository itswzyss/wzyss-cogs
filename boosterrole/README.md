# BoosterRole

Track booster custom roles and remove them when a user stops boosting.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs boosterrole
[p]load boosterrole
```
