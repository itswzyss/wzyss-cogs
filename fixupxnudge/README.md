# FixupXNudge

Gently nudge users to use fixupx.com for X/Twitter post links.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs fixupxnudge
[p]load fixupxnudge
```
