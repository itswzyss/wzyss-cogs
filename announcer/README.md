# Announcer

Forward channel messages to subscribed role members via DM, with a 📢 confirmation step.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs announcer
[p]load announcer
```
