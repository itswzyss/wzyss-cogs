# ListingInterest

Interest buttons on product listings that open private channels and notify sellers.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs listinginterest
[p]load listinginterest
```
