# ChannelMigrate

Copy every message from a channel to a channel in another server for migrations.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs channelmigrate
[p]load channelmigrate
```
