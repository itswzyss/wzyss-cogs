# RoleToggle

Post self-role toggle buttons when configured roles are pinged.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs roletoggle
[p]load roletoggle
```
