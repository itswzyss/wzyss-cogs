# Clear

Clear/purge messages in a channel (by count, after a message, between messages, or by user).

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs clear
[p]load clear
```
