# SelfRoles

Interactive builder for self-assignable roles with buttons, reactions, and commands.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs selfroles
[p]load selfroles
```
