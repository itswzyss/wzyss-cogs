# ServerTemplate

Back up a server's roles, channels, permissions, and settings and replicate them to other servers.

## Installation

```
[p]repo add wzyss-cogs https://github.com/itswzyss/wzyss-cogs
[p]cog install wzyss-cogs servertemplate
[p]load servertemplate
```
